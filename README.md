# Ledger Lab

Jogo de treino para o exame de Financial Accounting (semanas 1–6).

- **Definitions**: 48 fichas com definição, porque importa e exemplo, mais um quiz.
- **Memorise the lists**: as 50 palavras das listas do curso para escrever de memória, e o jogo «Which one is missing?».
- **Name that concept**: 564 perguntas em três níveis, com escolha múltipla ou resposta escrita.
- **Mock midterms**: 7 exames com casos de empresas, 84 perguntas em que só uma de quatro respostas é a melhor.

Tudo está num único ficheiro, `index.html`, sem dependências além das Google Fonts.
